# Why there is no front end

A document desk needs reliable originals, metadata, a review history and a way to ask for the right record. This base keeps those in a database. A coding agent runs the same commands an operator can inspect and repeat.

Read-only branded HTML gives the team a weekly desk, a filing register and retention findings. It has no buttons that change records. Revision records and review requests can be printed as working papers. Original files can be recovered without opening or executing them.

A screen gives people capabilities this base does not: drag-and-drop filing, in-browser PDF previews, mobile capture, Office co-authoring, offline synchronisation and self-service access for staff. The base has no OCR, e-signature service, authenticated sharing, desktop sync or permissions portal. Its content search covers metadata and UTF-8 text files, not the contents of PDFs or Office documents.

Enterprise DNA scopes those connections and screens for an owned version when the business needs them. Use this base where a trusted operator can handle document filing and review by conversation. It is not a replacement for a regulated records platform or an organisation-wide collaboration deployment without that work.
